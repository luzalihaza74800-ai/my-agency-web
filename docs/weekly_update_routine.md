# 台中市預售屋名單每週滾動更新流程

## 1) 每週固定節點
- 建議更新日：每週一上午。
- 更新步驟：更新 `data/taichung_presale_projects.csv` → 重新產表 → 發布當週重點名單。

## 2) 執行指令
```bash
python3 scripts/build_taichung_presale_table.py
```

執行後會更新：
- `output/taichung_presale_strategy_table.csv`
- `output/taichung_presale_strategy_table.md`

## 3) 更新時必看欄位
- `預計完工日`：若建案公告從「季度」改為「月份」，應以月份為準。
- `價格指標(萬/戶)`：優先使用建案總價，若無則使用近期成交總價。
- `價格階段`：系統會依目前有效價格樣本重算五分位（Tier 1~5）。
- `半年內完工標注`：0~183 天自動標為 `★重點`。

## 4) 開發優先順序（實務）
1. 先看 `半年內完工標注 = ★重點`。
2. 在 `★重點` 中，優先處理 `Tier 1~3`（通常轉換較快）。
3. `Tier 4~5` 以高資產客與精準名單經營為主。

## 5) 品質控管清單
- 完工日空白：標記為待補件，不納入重點案。
- 價格空白：標記為待補件，不進行 tier 分級。
- 建案名稱重複：以「建案名稱 + 行政區 + 預計完工日」去重。
- 異常價格：若落在明顯極端值，先回原頁確認後再納入。

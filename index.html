Leadership Conflict Assessment

領導者高衝突評鑑題本

在高衝突、多重壓力與無標準答案的情境中，看見你真正優先保護的是什麼。

這不是對錯測驗，而是一份取捨與代價的測驗。你要做的不是把自己寫成完美領導者，而是誠實呈現：當四種重要價值無法同時被保住時，你會先保什麼、願意失去什麼、最害怕失去什麼。

作答說明

請以真實偏好作答，而不是填寫理想答案。每題都需要做出分配、說明理由，並正視你最不願意選擇的方向。

分數規則

  • 每題有 A / B / C / D 四個選項。
  • 請將 10 分 分配給四個選項，可為 0 分。
  • 每題四個選項加總 必須等於 10。

每題必填內容

  • 核心理由
  • 願意承擔的代價
  • 最不願意選的方向（A / B / C / D）

評鑑提醒

  • 沒有標準答案，也不是價值高下排序。
  • 重點在於你此刻先保護什麼，而不是事後如何包裝。
  • 高成熟度常來自對代價的清楚，而不是對立場的漂亮描述。

附加功能

  • 系統會即時計算每題總分與整體進度。
  • 作答內容會自動暫存於本機瀏覽器。
  • 提交後可列印結果、匯出 JSON，並展開查看逐題摘要。

作答進度

0 / 12
  • 尚未完成任何題目
  • 尚未檢查分數加總
  • 本機暫存：尚未儲存

快速跳題

可快速跳到任一題；完成題目會維持綠色提示。

提交前系統會檢查每題是否填妥、總分是否等於 10，以及是否有遺漏的理由、代價與最不願選方向。

評鑑結果

提交後將顯示你的四向度總分、主要傾向與文字解讀。

    成熟度判斷提示

    成熟的受測者通常不急著把自己寫成兼顧一切的人，而是能清楚說出自己在當下先保什麼、願付什麼代價。

    1. 不會每題平均分配。
    2. 理由裡會談代價，而不只談立場。
    3. 能承認自己最怕失去什麼。
    4. 不會把自己寫成永遠兼顧一切的人。
    5. 能分清「此刻先保什麼」與「之後怎麼補救」。
